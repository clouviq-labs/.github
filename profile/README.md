# ClouViQ Labs

We build small services and ship them with GitHub Actions.

## Start a new service

1. Open [service-template](https://github.com/clouviq-labs/service-template) and click **Use this template**.
2. Name it `<domain>-<purpose>`: `payments-api`, `orders-worker`, `docs-site`.
3. Set the `team` custom property, so everyone knows who owns it.

Every repo is open to every team: read the code, open an issue, send a pull request.
